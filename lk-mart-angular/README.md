# LK Mart Angular

Современная версия приложения LK Mart, переписанная с AngularJS на Angular 20.

## Описание

Это приложение представляет собой систему управления документами, которая работает в iframe и взаимодействует с родительским окном через ELK.pubsub механизм.

## Основные возможности

- Отображение списка документов с пагинацией
- Выбор навигационных узлов через модальное окно
- Интеграция с ELK.pubsub для взаимодействия с родительским окном
- Современный UI с использованием Angular Material
- TypeScript для типобезопасности


### Сборка для продакшена

```bash

```

### Запуск тестов

```bash
ng test
```

## Интеграция с ELK

Приложение интегрируется с родительским окном через ELK.pubsub механизм:

- **Подписка на события**: `PubsubService.subscribe()`
- **Публикация событий**: `PubsubService.publish()`
- **Специальные события**: выбор узлов, открытие документов, обновление данных

## Компоненты

### DocumentTableComponent

Отображает таблицу документов с возможностью:
- Пагинации
- Фильтрации
- Выбора режима отображения
- Открытия документов

### NavigationNodesModalComponent

Модальное окно для выбора навигационных узлов:
- Отображение списка узлов
- Выбор узла
- Подтверждение выбора

## Сервисы

### PubsubService

Центральный сервис для работы с ELK.pubsub:
- Проверка доступности ELK
- Подписка/публикация событий
- Специализированные методы для различных типов событий

### NavigationNodesService

Сервис для работы с навигационными узлами:
- Получение узлов из родительского окна
- Обработка таймаутов
- Управление запросами

### DocumentApiService

API сервис для работы с документами:
- CRUD операции
- Поиск и фильтрация
- Пагинация

## Разработка

### Добавление нового компонента


### Добавление нового сервиса

```bash

```

Добавьте интерфейсы в `src/app/models/types.ts`
